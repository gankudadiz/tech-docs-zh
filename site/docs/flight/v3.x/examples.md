# 需要快速入门？

两个选项开始新的 Flight 项目：

- [完整 Skeleton 模板](https://github.com/flightphp/skeleton)：包含控制器和视图的完整示例。
- [单文件 Skeleton 模板](https://github.com/flightphp/skeleton-simple)：一个文件包含运行应用的一切。

社区贡献示例：

- [flightravel](https://github.com/fadrian06-templates/flighravel)：Laravel 目录结构的 FlightPHP + PHP 工具 + GH Actions
- [fleact](https://github.com/flightphp/fleact) - ReactJS 集成的 FlightPHP 入门套件
- [flastro](https://github.com/flightphp/flastro) - Astro 集成的 FlightPHP 入门套件
- [velt](https://github.com/flightphp/velt) - Svelte 前端 + FlightPHP 后端
- [vite-flightphp](https://github.com/pauloramoscuba/vite-flightphp) - FlightPHP + Vite + Tailwind CSS 热重载
- [Decay](https://github.com/boxybird/decay) - Flight v3 + HTMX + SleekDB
- [Flight Example Blog](https://github.com/n0nag0n/flightphp-blog) - Flight v3 + Middleware + ActiveRecord + Latte
- 更多示例见[官方页面](https://docs.flightphp.com/examples)
