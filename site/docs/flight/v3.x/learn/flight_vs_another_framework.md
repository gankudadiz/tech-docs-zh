# Flight 与其他框架对比

如果你正在从其他框架（如 Laravel、Slim、Fat-Free 或 Symfony）迁移到 Flight，本页面将帮助你理解两者之间的差异。

## Laravel

Laravel 是一个全功能框架，拥有华丽的功能和出色的以开发者为中心的生态系统，但代价是性能和复杂性。

[查看 Laravel 与 Flight 的对比](flight_vs_laravel)。

## Slim

Slim 是一个与 Flight 类似的微框架。它设计为轻量且易于使用，但可能比 Flight 稍微复杂一些。

[查看 Slim 与 Flight 的对比](flight_vs_slim)。

## Fat-Free

Fat-Free 是一个以更小体量提供的全栈框架。虽然它拥有工具箱中的所有工具，但其数据架构可能使某些项目变得比需要的更复杂。

[查看 Fat-Free 与 Flight 的对比](flight_vs_fat_free)。

## Symfony

Symfony 是一个模块化的、企业级框架，设计为灵活和可扩展。对于较小的项目或较新的开发者，Symfony 可能会有些令人不知所措。

[查看 Symfony 与 Flight 的对比](flight_vs_symfony)。
