# Plans

## 目录结构

```text
plans/
├── 进行中/     当前正在执行或待推进的计划
└── 已归档/     已完成、暂停或被替代的计划
```

## 使用约定

- 每个计划文件对应一个明确产品和版本。
- 执行前先读 `docs/05_开发功能细则文档/00_工作流总览.md` 和计划中引用的工作流文档。
- 完成一个步骤后，把复选框从 `[ ]` 改成 `[x]`，并在必要时补充执行日期、命令或风险说明。
- 如果实际执行偏离计划，在计划文件中记录原因，不要只依赖聊天记录。
- 已完成的计划移入 `已归档/`，不要长期堆在根目录。
