# Plans

这里存放可执行的阶段计划和步骤清单。`docs/` 目录维护长期工作流和项目文档，`plans/` 目录用于某个具体翻译目标的短中期执行跟踪。

- [Flight v3.x 翻译接入步骤](Flight_v3x_翻译接入步骤.md)：FlightPHP v3.x 翻译目标的分步清单。（已完成）
- [后续翻译计划与 Filament 修复方案](2026-05-28_01_后续翻译计划与Filament修复方案.md)：Filament broken links 修复、新版本接入评估、新产品翻译优先级规划。

## 使用约定

- 每个计划文件对应一个明确产品和版本。
- 执行前先读 `docs/05_开发功能细则文档/00_工作流总览.md` 和计划中引用的工作流文档。
- 完成一个步骤后，把复选框从 `[ ]` 改成 `[x]`，并在必要时补充执行日期、命令或风险说明。
- 如果实际执行偏离计划，在计划文件中记录原因，不要只依赖聊天记录。
