## 0. 依据和范围

执行前先阅读：

- `docs/05_开发功能细则文档/00_工作流总览.md`
- `docs/05_开发功能细则文档/01_文档采集与翻译工作流.md`

- `docs/05_开发功能细则文档/06_本地化超链接适配工作流.md`

固定上游来源：

```text
repository: https://github.com/marktext/marktext
ref: develop
docs path: packages/website/content/docs/
official docs URL: https://marktext.github.io/marktext/（待确认）
local product: marktext
local version: v1.x
```

核心边界：

- MarkText 是 Electron 桌面 Markdown 编辑器，非 Web 框架。本项目接入其用户文档和开发者文档。
- 文档源为纯 Markdown 文件，无框架组件（Astro、MDX 等）。
- 文档分为两大部分：end-user（21 页用户文档）和 dev（12 页开发者文档），另有 CHANGELOG 和顶层 README，共 35 个 Markdown 文件。
- 图片资源位于 `assets/` 目录（通过 `../assets/xxx.png` 相对路径引用），包含 PNG 截图和 GIF 演示。
- 开源协议：MIT License。
- 官方文档标注"Documentation is currently under development"，内容可能变动。

## 9. 与现有产品的差异

| 维度 | Filament / Livewire / Alpine / Flight | MarkText |
|------|---------------------------------------|----------|
| 产品类型 | PHP/JS Web 框架 | Electron 桌面应用 |
| 文档受众 | 开发者 | 终端用户 + 开发者 |
| 图片资源 | 少量或无 | 大量截图 + GIF 动图 |
| 框架组件 | 部分有 Astro/MDX 组件 | 纯 Markdown |
| 代码块语言 | php, blade, javascript, html | bash, json, yaml, typescript |
| 文档篇幅 | 每篇 0.5-50KB | 大部分较短，CHANGELOG 可能较长 |
| 版本策略 | 按框架版本分目录 | 桌面应用，版本化不明显 |
| 翻译难度 | 中等（框架概念复杂） | 低（面向用户，概念直观） |

## 10. 翻译注意事项

- MarkText 是桌面应用，文档中大量使用快捷键描述（如 `CmdOrCtrl+S`），翻译时保持快捷键原样。
- 偏好设置名称（如 `openFilesInSidebar`）是配置键，不翻译。
- 文档中可能引用 MarkText 内部菜单路径（如 `File > Open File`），翻译时保留英文菜单路径并在括号中注释中文。
- `IMAGE_UPLOADER_CONFIGRATION.md` 文件名有拼写错误（应为 Configuration），翻译时在标题中使用正确拼写。
- 开发者文档涉及 Electron、TypeScript、IPC 等技术概念，翻译时保持术语一致性。
