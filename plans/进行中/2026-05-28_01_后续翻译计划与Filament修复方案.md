## 1. A — 修复 Filament broken links

### 问题分析

Filament 43 条 broken links 属于同一模式：`../schemas` 此类链接指向目录而非具体文件（正确的 Docusaurus 路由应为 `../schemas/overview`）。每个 Filament 子目录都有 `overview.md` 作为首页。

**涉及目录**：`schemas/`、`tables/`、`forms/`、`notifications/`、`styling/`、`testing/`、`widgets/`、`actions/`、`plugins/`、`infolists/`、`resources/`、`users/`、`navigation/`

### 修复工作流

```bash
# 1. 预览模式，先看具体问题
python3 scripts/fix_relative_links.py site/docs/filament/v4.x/ --dry-run

# 2. 检查脚本是否能自动发现目录→overview 映射问题
#    （如果脚本检测到 ../schemas 而 schemas/overview.md 存在，
#    应自动建议为 ../schemas/overview）

# 3. 根据 build 输出的 broken links 逐个或分批修复：
#    ../schemas → ../schemas/overview
#    ../actions → ../actions/overview
#    ../forms   → ../forms/overview
#    ... 等模式替换

# 4. site/ 和 content/ 双目录同步
python3 scripts/fix_relative_links.py \
    site/docs/filament/v4.x/ \
    content/filament/v4.x/zh-cn/docs/

# 5. 构建验证
cd site && npm run build
```

### 验收标准

- [x] `npm run build` 中 0 条 Filament broken links
- [x] `npm run typecheck` 通过
- [x] `site/` 和 `content/` 修复数一致
- [x] 创建专用修复脚本 `scripts/fix_filamentv4_directory_links.py`

### 已知风险

- Filament 是 158 页的大文档，修复中可能发现更多隐藏问题
- `../schemas` 也可能指向具体子页（如 `../schemas/wizards`），不可一刀切替换

## 2. B — 新版本接入评估

### 评估流程

每个新版本接入前，先回答三个问题：

1. **变更范围**：新旧版本官方文档的 diff 有多大？
2. **破坏性变更**：框架是否与旧版本完全不兼容？
3. **上手时机**：新版是否已稳定（非 RC/beta）？

## 3. C — 新产品翻译优先级

### 评估维度

| 维度 | 权重 | 说明 |
|------|------|------|
| **用户价值** | 高 | 目标受众广泛程度 |
| **工作匹配** | 高 | 与现有翻译经验（PHP 生态）的复用度 |
| **文档规模** | 中 | 是否有合理的工作量（100-200 页以内最佳） |
| **官方中文** | 否决项 | 已有官方中文翻译的不重复搬运 |

### 候选列表

#### 第一梯队（推荐优先做）

| 项目 | 类型 | 预估规模 | 推荐理由 |
|------|------|---------|---------|
| **Slim Framework** | PHP 微框架 | ~50 页 | 与 Flight 同类，翻译经验和 `fix_relative_links.py` 脚本可直接复用 |
| **PHP The Right Way** | PHP 社区指南 | ~100 页 | PHP 开发者必读，覆盖面广，独立文档不需要依赖框架版本 |
| **Composer** | 依赖管理 | ~100 页 | 每个 PHP 项目都在用，官方文档全面 |

#### 第二梯队（可以考虑）

| 项目 | 类型 | 预估规模 | 备注 |
|------|------|---------|------|
| **PHPUnit** | 测试框架 | ~500+ 页 | 核心工具但太庞大，建议只翻译用户指南核心章节 |
| **Spatie/laravel-permission** | Laravel 包 | ~30 页 | 小而精，适合快速完成建立成就感 |
| **Spatie/laravel-medialibrary** | Laravel 包 | ~100 页 | 热门包，文档全面 |

#### 不推荐

| 项目 | 原因 |
|------|------|
| **Laravel** | 已有官方中文文档 |
| **Symfony** | 规模太大（数千页），且已有活跃的中文翻译社区 |
| **React/Vue** | 非 PHP 生态，与本项目定位不符（PHP 技术文档站） |

见 `docs/05_开发功能细则文档/04_新增产品或版本接入工作流.md`。
