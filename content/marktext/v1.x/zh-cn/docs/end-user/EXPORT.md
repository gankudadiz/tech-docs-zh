# 导出文档

MarkText 允许你将 Markdown 文档导出为 PDF 和 HTML 文件，或打印文档。

## 选项

### 页面选项

你可以在导出文档前设置页面大小、方向和边距。

### 样式

在不修改页面主题的情况下调整页面样式：

- 覆盖字体、字号和行高。
- 标题自动编号。
- 选择是否在导出的文档中显示 front matter。

### 主题

MarkText 允许你在导出前选择页面主题。你可以在[这里](EXPORT_THEMES.md)了解更多关于页面主题的信息。

### 页眉和页脚

如果你选择 PDF 或打印，可以在导出的文档中包含页眉和/或页脚，并调整页眉/页脚样式。在导出选项中，你可以选择无页眉、单行页眉或三栏页眉。定义后页眉和/或页脚会出现在每页上，页眉可以是多行但页脚只能是单行。遗憾的是，目前不支持页码编号。示例如下。
