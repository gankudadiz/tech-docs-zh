# 环境变量

| 名称 | 描述 |
| --- | --- |
| `MARKTEXT_DEBUG` | 启用调试模式。 |
| `MARKTEXT_DEBUG_KEYBOARD` | 启用调试模式时打印更多键盘信息。 |
| `MARKTEXT_ERROR_INTERACTION` | 不显示报告 bug 的错误对话框。 |
| `MARKTEXT_PANDOC` | 覆盖 pandoc 路径。 |

## 开发

| 名称 | 描述 |
| --- | --- |
| `MARKTEXT_EXIT_ON_ERROR` | 遇到第一个错误或异常时退出。 |
| `MARKTEXT_IS_STABLE` | **请勿使用！** 用于标识稳定版本。 |
