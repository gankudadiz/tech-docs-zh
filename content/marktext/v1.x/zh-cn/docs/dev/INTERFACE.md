# 界面

## 主界面

![](../assets/marktext-interface.png)

- 绿色：标题栏
- 橙色：侧边栏
- 红色：编辑器（含选项卡和底部的各选项卡通知栏）

### 标题栏

标题栏位于窗口顶部，在 Linux 和 Windows 上显示当前打开的文件路径和菜单。在 macOS 上，我们使用客户端装饰（CSD），外观类似于上图。在 Linux 和 Windows 上有两种标题栏：一种是你可以在上图中看到的自定义 CSD，另一种是原生标题栏。

### 侧边栏

侧边栏是 MarkText 的可选功能，包含三个面板且宽度可变。第一个面板是已打开根目录的树形视图；它还包含一个可折叠的 *已打开文件* 子区域（通过 `openedFilesInSidebar` 偏好设置切换）。后两个面板分别是由 ripgrep 驱动的文件夹搜索器（在文件中查找）和当前打开文档的目录大纲。

### 编辑器

编辑器是核心元素，承载着名为 Muya 的实时预览编辑器，由三个部分组成。选项卡位于顶部，底部是各选项卡通知栏，用于显示文件更改或删除等事件。主体部分是编辑器，由 Muya 提供实时预览编辑，或由 CodeMirror 提供源码编辑。还有多个覆盖层可用，如内联工具栏、表情选择器、快速插入或图片工具。
