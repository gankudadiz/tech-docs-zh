# 02. 翻译操作指南

**日期**: 2026-05-16
**状态**: 正式

本文档详细说明如何正确翻译文档并部署到站点，避免常见错误。

## 0. 链接处理规则

翻译文档时，内部链接需要特别注意：

### 已翻译文档的链接

确保链接指向正确的路径：

```markdown
# 错误：指向目录
[资源文档](resources)

# 正确：指向具体文档
[资源文档](resources/overview)
```

### 尚未翻译的文档

对于尚未翻译的文档，站点中已有占位页面，链接可以正常指向：

```markdown
# 这些链接会指向占位页面，显示"翻译中"
[表单](../forms)
[表格](../tables)
[导航](../navigation)
```

### 外部链接

外部链接保持原样即可：

```markdown
[Livewire 组件](https://livewire.laravel.com/docs/components)
```

## 1. 翻译前准备

### 1.1 确认源文件位置

源文件位于 `sources/filament/v4.x/normalized/docs/` 目录。

```bash
# 查看可用的源文件
find sources/filament/v4.x/normalized/docs -name "*.md" -type f
```

### 1.2 理解路径差异

| 目录 | 图片路径格式 | 用途 |
|------|-------------|------|
| `sources/.../normalized/` | 相对路径 `../../raw-assets/...` | 源文件，用于翻译参考 |
| `site/docs/` | 绝对路径 `/assets/filament/v4.x/...` | 站点文件，用户可见 |

**这是最容易出错的地方！** 翻译时必须转换图片路径。

## 2. 翻译流程

### 步骤 1：读取源文件

```bash
# 示例：读取 overview.md
cat sources/filament/v4.x/normalized/docs/01-introduction/01-overview.md
```

### 步骤 2：翻译内容

翻译时注意：
- 保留所有 Markdown 格式
- 代码块不翻译
- 技术术语保持一致（参考术语表）
- 图片路径**先保留原样**，后续统一处理

### 步骤 3：存储翻译成果（归档）

将翻译后的内容保存到 `content/` 目录：

```bash
# 创建目录结构
mkdir -p content/filament/v4.x/zh-cn/docs/01-introduction

# 保存翻译文件
# content/filament/v4.x/zh-cn/docs/01-introduction/01-overview.md
```

### 步骤 4：部署到站点（关键步骤！）

**必须执行以下操作：**

1. 复制文件到 `site/docs/`
2. 修复图片路径

```bash
# 1. 复制文件
cp content/filament/v4.x/zh-cn/docs/01-introduction/01-overview.md \
   site/docs/filament/v4.x/introduction/overview.md

# 2. 修复图片路径
# 将 ../../raw-assets/docs-assets/ 替换为 /assets/filament/v4.x/
# 将 ../../../raw-assets/docs-assets/ 替换为 /assets/filament/v4.x/
```

## 3. 图片路径转换规则详解

### 3.1 路径对照表

| 源文件中的路径 | 站点中正确的路径 |
|--------------|----------------|
| `../../raw-assets/docs-assets/screenshots/images/light/panels/dashboard.jpg` | `/assets/filament/v4.x/screenshots/images/light/panels/dashboard.jpg` |
| `../../../raw-assets/docs-assets/screenshots/images/light/panels/resources/listing.jpg` | `/assets/filament/v4.x/screenshots/images/light/panels/resources/listing.jpg` |

### 3.2 转换逻辑

```
原始：../../raw-assets/docs-assets/screenshots/...
转换：/assets/filament/v4.x/screenshots/...

规则：
1. 去掉所有 ../ 前缀
2. 去掉 raw-assets/docs-assets/ 层级
3. 添加 /assets/filament/v4.x/ 前缀
4. 使用绝对路径（以 / 开头）
```

### 3.3 批量转换命令

```bash
# 对单个文件进行路径转换
sed -i 's|\.\./\.\./raw-assets/docs-assets/|/assets/filament/v4.x/|g' site/docs/filament/v4.x/introduction/overview.md
sed -i 's|\.\./\.\./\.\./raw-assets/docs-assets/|/assets/filament/v4.x/|g' site/docs/filament/v4.x/introduction/overview.md

# 对目录下所有文件进行批量转换
find site/docs/filament/v4.x -name "*.md" -exec \
  sed -i 's|\.\./\.\./raw-assets/docs-assets/|/assets/filament/v4.x/|g' {} \;
find site/docs/filament/v4.x -name "*.md" -exec \
  sed -i 's|\.\./\.\./\.\./raw-assets/docs-assets/|/assets/filament/v4.x/|g' {} \;
```

## 4. 完整翻译示例

以翻译 `01-introduction/01-overview.md` 为例：

```bash
# 1. 读取源文件
cat sources/filament/v4.x/normalized/docs/01-introduction/01-overview.md

# 2. 进行翻译（在编辑器或 AI 工具中完成）

# 3. 保存翻译成果到 content/
# 文件：content/filament/v4.x/zh-cn/docs/01-introduction/01-overview.md

# 4. 复制到站点目录
cp content/filament/v4.x/zh-cn/docs/01-introduction/01-overview.md \
   site/docs/filament/v4.x/introduction/overview.md

# 5. 修复图片路径
sed -i 's|\.\./\.\./raw-assets/docs-assets/|/assets/filament/v4.x/|g' \
  site/docs/filament/v4.x/introduction/overview.md

# 6. 验证路径是否正确
grep -n "raw-assets" site/docs/filament/v4.x/introduction/overview.md
# 应该没有输出，表示所有路径都已修复

# 7. 检查站点是否正常
# 访问 http://127.0.0.1:48763/docs/filament/v4.x/introduction/overview
```

## 5. 验证清单

翻译完成后，逐项检查：

- [ ] 文件已复制到 `site/docs/filament/v4.x/` 对应位置
- [ ] 图片路径已从相对路径转换为绝对路径
- [ ] 没有残留的 `raw-assets` 路径（用 grep 检查）
- [ ] 页面能正常加载，图片显示正常
- [ ] 代码块未被误翻译
- [ ] 内链指向正确的站内路径
- [ ] 翻译成果已归档到 `content/` 目录

## 6. 常见问题

### Q: 为什么图片加载失败？

A: 最可能的原因是图片路径没有从相对路径转换为绝对路径。检查是否还有 `raw-assets` 残留。

```bash
grep -r "raw-assets" site/docs/filament/v4.x/
```

### Q: 为什么 content/ 和 site/docs/ 内容不一致？

A: `content/` 是归档，`site/docs/` 是站点实际读取的目录。翻译后需要手动复制并修复路径。

### Q: 新增文档文件时需要注意什么？

A: 确保：
1. 在 `site/docs/` 中创建对应的目录结构
2. 在 `site/sidebars.ts` 中添加侧边栏配置（如需要）
3. 图片使用绝对路径 `/assets/filament/v4.x/...`
