- 新增 `00_工作流总览.md`，作为 05 目录入口，统一任务类型、路径变量和最小验收清单。
- 新增 `04_新增产品或版本接入工作流.md`，明确同一产品新版本与全新产品的不同处理方式。

## 4. 验证收口

本次为项目文档改造，不涉及站点运行代码。后续执行真实翻译或新版本接入时，应按 `00_工作流总览.md` 的最小验收清单运行 `npm run typecheck` 和 `npm run build`。

## 5. 本阶段收益

05 目录从原则说明升级为可执行 SOP。后续 Agent 可以先根据任务类型选择流程，再按参数化路径完成采集、翻译、入站、校对和版本入口同步。
