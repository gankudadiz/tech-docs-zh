# 04. Filament v4.x 侧边栏结构调整记录

**日期**: 2026-05-17  
**阶段**: 导航结构收口

## 1. 需求背景

原侧边栏把站点总入口、产品版本和章节混在同一棵树里，左侧会先出现 `中文技术文档站` / `Filament v4.x` 这类外层入口。后续如果继续接入 Laravel 等产品，这种结构会让不同产品共用同一个左侧栏，阅读路径不清晰。

## 2. 关联提交

当前尚未形成独立提交。本记录依据 2026-05-17 工作区中 `site/sidebars.ts`、`site/docusaurus.config.ts` 和项目文档变更编写。

## 3. 实现要点

- 将 Docusaurus 侧边栏从 `tutorialSidebar` 调整为 Filament v4.x 专属的 `filamentV4Sidebar`。
- 移除侧边栏中的站点级 `intro` 和产品级 `Filament v4.x` 外层分类。
- 让左侧顶层直接显示当前产品/版本的章节分类，例如 `介绍`、`资源`、`组件`。
- 将顶部文档入口标签调整为 `Filament v4.x`，产品/版本选择由首页和顶部导航承担。
- 同步项目文档中的目录结构、UI 标准、翻译操作指南和校对清单，明确后续新增产品/版本必须使用独立 sidebar。

## 4. 验证收口

- `npm run build` 可成功生成静态站点。
- 构建仍提示现有 broken links / anchors，原因是 Filament v4.x 仍处于分批翻译接入阶段，与本次侧边栏结构调整无关。

## 5. 本阶段收益

侧边栏职责被固定为“当前产品/版本的阅读目录”。后续接入 Laravel 等新产品时，应新增独立 sidebar id 和入口，不再把多个产品混入同一个左侧导航。
