# 01. 本地开发环境约定

**日期**: 2026-05-16  
**当前状态**: Docusaurus 本地站已初始化

## 1. 运行目标

本项目只要求本地运行，不做线上部署。

默认访问地址：

```text
http://127.0.0.1:48763
```

## 2. 依赖建议

当前已使用：

- Node.js LTS
- npm
- Docusaurus 3.10.1
- TypeScript

前端依赖安装在 `site/` 目录，`site/node_modules/` 不纳入版本管理。

## 3. 后续命令约定

当前 `site/package.json` 已固定本地启动端口：

```json
{
  "scripts": {
    "start": "docusaurus start --host 127.0.0.1 --port 48763",
    "build": "docusaurus build",
    "serve": "docusaurus serve"
  }
}
```

这样可以避免和其他本地项目常用端口冲突。

## 4. WSL2 代理

本机 WSL2 已安装 mihomo，并创建了用户级 systemd 服务：

```bash
systemctl --user start mihomo
systemctl --user stop mihomo
systemctl --user status mihomo
```

服务监听：

```text
127.0.0.1:7890
```

需要让命令走代理时，可临时设置：

```bash
export http_proxy=http://127.0.0.1:7890
export https_proxy=http://127.0.0.1:7890
```

## 5. 当前不需要的服务

- 不需要 MySQL。
- 不需要 Redis。
- 不需要队列。
- 不需要 Nginx。
- 不需要 Laravel Sail 或 Docker。

只有后续引入后台管理、任务队列或多人审核流时，才重新评估这些服务。
